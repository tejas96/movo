| Asset | Use | Source | License |
| --- | --- | --- | --- |
| Poppins (400, 500, 600, 700) | every piece of UI text, English, Hindi and Marathi (Poppins ships Devanagari) | `@expo-google-fonts/poppins` (Indian Type Foundry, via Google Fonts) | SIL OFL 1.1 (`OFL-Poppins.txt`) |

Regenerate: `pnpm --filter @movo/design-system fonts` and `pnpm --filter @movo/design-system icons`.
Keep the font file names: Android resolves a font by file name.
