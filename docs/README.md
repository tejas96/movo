This folder is the plan. Code follows the plan.

Status words used in the docs:

- **DECIDED** — I chose this. Reasons are given. Say so if you disagree.
- **PROPOSED** — my recommendation. Needs your yes.
- **OPEN** — needs facts only you have.
- **LATER** — not in the MVP. Architecture keeps room for it.
